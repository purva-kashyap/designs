# Designs

This repository contains various design projects.

## Space Soldier Helmet - Paint by Numbers

A Star Wars-inspired Stormtrooper paint-by-numbers activity designed for older kids. This original design features a recognizable helmet with clearly defined sections perfect for painting.

### Features
- **10 numbered sections** for easy painting
- **Grayscale color palette** (white, light gray, medium gray, dark gray, very dark gray, black)
- **A4 size compatible** (210mm x 297mm) - ready to print
- **Original design** inspired by but not identical to Star Wars Stormtroopers
- Includes visor, dome, and mouth grill details

### Files
- `stormtrooper-paint-by-numbers.svg` - Vector graphic file (editable, scalable)
- `stormtrooper-paint-by-numbers.png` - PNG preview (2480 x 3508 pixels at 300 DPI)

### How to Use
1. Print the SVG or PNG file on A4 paper
2. Use the color key at the bottom to match numbers with colors
3. Paint each numbered section with the corresponding grayscale shade
4. Use paint, markers, or colored pencils!

### Printing Tips
- For best results, print on cardstock or heavyweight paper
- Use the SVG file for highest quality scaling
- Recommended print size: A4 (8.3" x 11.7")
